# 20_PERSONAL/AGENTS.md — 個人領域のルール

> 共通ルールはルートの `AGENTS.md` が正本。ここでは個人領域で特に気をつけることを足します（どのAIツールでも同じです）。
> 20_PERSONAL はこのVaultの中核です。プライバシー性が最も高い情報が入るため、他のフォルダより慎重に扱ってください。

各フォルダの `<フォルダ名>.md` に、推奨ノート例と頼み方の例があります。

## 人のノートの置き場所

- 家族の人物ノートの正本は `家族/家族_名前.md`（例: `家族_花子.md`）。1人1ノート
- `教育・子育て/` や `医療・健康/` のノートは、その人のプロフィールを書き直さず `[[家族_花子]]` のようにリンクする
- 家族以外の人は `50_PEOPLE/` に置く

## フォルダ間のつながり

- `医療・健康` → `税務`（医療費控除）
- `保険` → `医療・健康`（給付請求）／`税務`（保険料控除）
- `保険` ← `車・乗り物`（自動車保険）／`住まい`（火災保険）
- `財務` → `税務`（収入・控除の根拠）
- `仕事・キャリア` → `税務`（源泉徴収票）
- `家族` ← `教育・子育て`・`医療・健康`（誰のことか）
- `保険`・`財務`・`アカウント・契約`・`家族`・`住まい`・`車・乗り物` → `もしもの時`（リンク集に載せる）

ノートを新しく作ったら、上のつながりに沿って `[[wikilink]]` を張ってください。`もしもの時` への登録漏れがあれば指摘してください。

## プライバシールール

- **書かないもの**: マイナンバー・パスワード・暗証番号・口座番号やカード番号や証券番号の **全桁**。番号類は **末尾4桁まで**
- ユーザーが全桁を書こうとしていたら、末尾4桁にすることを提案する
- **医療・家族のノートを読むよう頼まれたら、断らずに読む。** どのノートをAIに読ませるかはユーザーが決めることです（クラウドのAIに読ませると内容がAIの提供元に送られることは、ユーザー向けに README で説明済み）
- ただし、医療・家族の情報を **外部サービス（Web検索・翻訳・外部API・共有リンク・その他のSaaSなど、ユーザーが選んだAIツール以外のもの）へ送らない**。その他の個人情報も、外部サービスに送る前に必ず確認する
- 医療・家族の中身（金額・病名・家族の情報など）を **関係のない場所へ写さない**: `30_WORK/`・`50_PEOPLE/`・`70_TOPICS/` など他の領域のノート、AI のメモリ（記憶機能）、外部ツールへ転記しない。必要ならリンクだけにする
- 例外: ユーザーに集計を頼まれたときは、頼まれた合計と内訳、元ノートへのリンクを `00_AI/reports/personal/` のレポートに書いてよい。書くのは頼まれたことに必要な最小限だけにする
- AI のメモリには「どこに何があるか」までにとどめ、中身（金額・病名・家族の情報）は書かない

## 集計（合計・一覧）をするときのルール

医療費・保険料・サブスク・資産などを集計するときは、次を守ってください。

1. **元ノートへのリンクを付ける** — 合計に使った各ノートを `[[wikilink]]` で列挙する（検算できるように）
2. **計算日を書く** — 「YYYY-MM-DD 時点」と明記する（`date` コマンドで取得）
3. **結果は `00_AI/reports/personal/` に保存する** — 例: `00_AI/reports/personal/20261027_医療費集計_2026.md`。元ノートは書き換えない。書くのは頼まれた合計と内訳・元ノートへのリンクなど、必要な最小限だけにする
4. 金額が読み取れないノート・判断に迷うノートは合計に含めず、別に列挙する
5. 医療費は「支払額 − 補填額（保険金・高額療養費など）」で集計し、`控除対象の判定` が「要確認」のものは別に列挙する。医療費控除の金額そのものは、国税庁のルールで確認するか税理士に確認するよう添える
