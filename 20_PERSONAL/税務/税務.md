# 税務

## 何を置くか

確定申告・源泉徴収票・ふるさと納税・医療費控除・住民税など、税金に関する記録を **年ごと** に置きます。

## 推奨ノート例

- `確定申告_YYYY.md` — その年の申告内容・提出日・控除の内訳（例: `確定申告_2026.md`）
- `源泉徴収票_YYYY.md` — 支払金額・源泉徴収税額などの転記
- `ふるさと納税_YYYY.md` — 寄付先・金額・ワンストップ特例の申請状況
- `住民税_YYYY.md` — 税額決定通知書の内容

## 他フォルダとのつながり

- ← [[医療・健康]]（医療費控除）
- ← [[保険]]（生命保険料控除）
- ← [[財務]]（収入・支出）
- ← [[仕事・キャリア]]（源泉徴収票）
