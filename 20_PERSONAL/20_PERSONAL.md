# 20_PERSONAL

**このVaultの中核** です。暮らしに関わる情報（家族・健康・保険・お金・税金・住まい・契約など）を、分野ごとのフォルダに整理します。
ばらばらの書類やアプリに散らばった情報をここに集めると、AI が「今年の医療費の合計」「更新が近い保険」「来月のサブスク」などをすぐに答えられるようになります。

## フォルダ

| | フォルダ | 置くもの |
|---|---|---|
| 👪 | [[家族]] | 家族1人1ノート（`家族_名前.md`）・緊急連絡先・記念日 |
| 🏥 | [[医療・健康]] | 通院・処方・検診・医療費 |
| 🛡️ | [[保険]] | 保険（契約ごとに1ノート） |
| 💰 | [[財務]] | 家計・口座・資産・ローン・クレカ |
| 🧾 | [[税務]] | 確定申告・ふるさと納税・住民税 |
| 🏠 | [[住まい]] | 契約・修繕・家電の保証書 |
| 🚗 | [[車・乗り物]] | 車検・整備（保険の契約ノートは [[保険]]） |

## はじめ方

最初は全部を埋めようとせず、**[[保険]] の一覧づくり** か **[[アカウント・契約]] のサブスク棚卸し** から始めるのがおすすめです。手元の書類やカード明細を見ながら、1件1ノートで書き出してみてください。

> [!warning] マイナンバー・パスワード・口座番号や証券番号の全桁は書かない（番号は末尾4桁まで）。AI 向けの詳しいルールは `20_PERSONAL/AGENTS.md`。
