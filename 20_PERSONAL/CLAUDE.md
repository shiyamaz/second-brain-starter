# 20_PERSONAL/CLAUDE.md — 個人領域のルール

> 共通ルールはルートの `AGENTS.md` が正本。ここでは個人領域で特に気をつけることだけを補足します。
> 20_PERSONAL はこのVaultの中核です。プライバシー性が最も高い情報が入るため、他のフォルダより慎重に扱ってください。

各フォルダの `<フォルダ名>.md` に、推奨ノート例と頼み方の例があります。

## フォルダ間のつながり

- `医療・健康` → `税務`（医療費控除）
- `保険` → `医療・健康`（給付請求）／`税務`（保険料控除）
- `財務` → `税務`（収入・控除の根拠）
- `仕事・キャリア` → `税務`（源泉徴収票）
- `保険`・`財務`・`アカウント・契約`・`家族`・`住まい`・`車・乗り物` → `もしもの時`（リンク集に載せる）

ノートを新しく作ったら、上のつながりに沿って `[[wikilink]]` を張ってください。`もしもの時` への登録漏れがあれば指摘してください。

## プライバシールール

- **書かないもの**: マイナンバー・パスワード・暗証番号・口座番号やカード番号や証券番号の **全桁**。番号類は **末尾4桁まで**
- ユーザーが全桁を書こうとしていたら、末尾4桁にすることを提案する
- **医療・家族の情報を外部サービスへ送らない**（Web検索・外部API・翻訳・共有リンクを含む）。その他の個人情報も、外部に送る前に必ず確認する
- 個人情報を `30_WORK/` など他の領域へ転記しない。必要ならリンクだけにする
- AI の memory には「どこに何があるか」までにとどめ、中身（金額・病名・家族の情報）は書かない

## 集計（合計・一覧）をするときのルール

医療費・保険料・サブスク・資産などを集計するときは、次を守ってください。

1. **元ノートへのリンクを付ける** — 合計に使った各ノートを `[[wikilink]]` で列挙する（検算できるように）
2. **計算日を書く** — 「YYYY-MM-DD 時点」と明記する（`date` コマンドで取得）
3. **結果は `00_AI/reports/` に保存する** — 例: `00_AI/reports/20261027_医療費集計_2026.md`。元ノートは書き換えない
4. 金額が読み取れないノート・判断に迷うノートは合計に含めず、別に列挙する
