# もしもの時

## 何を置くか

自分に何かあったとき、**家族がここを見れば分かる** ようにする「どこに何があるか」のリンク集です（エンディングノート的な役割）。
情報そのものはそれぞれのフォルダに置き、ここからはリンクするだけにします。

## 推奨ノート例

- `もしもの時の案内.md` — 最初に読むページ。下記へのリンクと、家族へのメッセージ
- `連絡してほしい人.md` — 勤務先・友人・専門家（[[家族]] の緊急連絡先へのリンク）
- `手続きチェックリスト.md` — 保険請求・口座・サブスク解約などの手順

## 他フォルダとのつながり

- ← [[保険]]（保険一覧）
- ← [[財務]]（口座一覧・ローン）
- ← [[アカウント・契約]]（サブスク一覧）
- ← [[家族]]（緊急連絡先）
- ← [[住まい]]／[[車・乗り物]]（契約・名義）

## AIへの頼み方の例

- 「保険・財務・アカウント・契約のノートから、もしもの時の案内.md のリンク集を作り直して」
- 「もしもの時の案内.md から辿れない保険や口座がないか確認して」
