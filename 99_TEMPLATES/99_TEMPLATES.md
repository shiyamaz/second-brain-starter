# 99_TEMPLATES

ノートのテンプレートです。Obsidian のコアプラグイン「テンプレート」でテンプレートフォルダに `99_TEMPLATES` を指定すると、`{{date}}` `{{time}}` `{{title}}` が自動で埋まります。

| ファイル | 用途 |
|---|---|
| `person` | 人（50_PEOPLE） |
| `organization` | 組織（60_ORGANIZATIONS） |
| `topic` | テーマ（70_TOPICS） |
| `project` | プロジェクト（30_WORK/projects） |
| `daily` | デイリーノート（02_DAILY） |
| `insurance` | 保険（20_PERSONAL/保険） |
| `medical` | 受診記録（20_PERSONAL/医療・健康） |
| `subscription` | サブスク・契約（20_PERSONAL/アカウント・契約） |
| `trip` | 旅行（20_PERSONAL/旅行） |

AI がテンプレートを使うときは、`{{date}}` などを実際の日時（ISO 8601 + タイムゾーン）に置き換えます。
