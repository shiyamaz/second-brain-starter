# second-brain-starter — Obsidian × AI で始める「第2の脳」

Obsidian のフォルダ（Vault）に、AI が迷わず働けるルールとフォルダ構成をあらかじめ用意したスターターキットです。
ダウンロードして Obsidian で開き、同じフォルダで AI ツール（Claude Code / Codex / Cursor など）を起動すれば、すぐに「メモを書く → AI が整理する → 知識がつながっていく」運用を始められます。

- 対象: Obsidian を少し触ったことがあるビジネスパーソン（AI は初心者でOK）
- 必要なもの: [Obsidian](https://obsidian.md/)（無料）と、フォルダを読み書きできる AI ツールのどれか1つ

> [!WARNING]
> **GitHub の「Use this template」を使うときは、必ず「Private」を選んでください。** Public のまま暮らしの情報（家族・医療・保険・お金）を書くと、世界中に公開されます。
> いちばん簡単で安全なのは、**ZIP をダウンロードして手元のパソコンだけで使う** ことです（→「入手方法」）。

---

## これは何か

「第2の脳」とは、頭の中に置いておくと忘れてしまう情報（人・会社・仕事・考えたこと）を外に書き出し、あとから取り出せるようにする仕組みです。
このキットは次の3つを用意しています。

1. **フォルダ構成** — 人・組織・テーマ・仕事の4つの軸で情報を整理する
2. **AI 向けルール**（`AGENTS.md`） — どの AI でも同じルールで動くようにする
3. **テンプレートとサンプル** — 何をどう書けばいいかが一目でわかる

## 入手方法

どちらか一方を選びます。迷ったら **A（ZIP）** にしてください。

- **A. ZIP をダウンロード（おすすめ・いちばん簡単）**: GitHub のページで「Code → Download ZIP」を押し、好きな場所に展開します。ノートはあなたのパソコンの中だけに残ります
- **B. 「Use this template」で自分用のリポジトリを作る（GitHub に慣れた人向け）**: 作成画面で **必ず「Private」を選んでください**。Public を選ぶと、あとで書く個人的なノートが誰でも見られる状態になります
  - 作っただけでは、まだパソコンの中にフォルダがありません。**あとで GitHub にバックアップし続けたいなら、手元へのコピーは「クローン」にしてください**（初心者には **GitHub Desktop** がいちばん簡単です。`git clone` でも同じです）。この手元のフォルダを Obsidian で開きます
  - 「Code → Download ZIP」は、その時点の中身をコピーするだけで、GitHub とはつながりません。ZIP で展開したフォルダには、下の「GitHubに上げる前のチェック」は関係ありません（そのまま手元だけで使えます）

### GitHubに上げる前のチェック

B を選んでクローンした人や、あとから GitHub でバックアップしたくなった人は、push する前に確認してください。ZIP で手元に置いただけで GitHub につないでいない人は、このチェックは不要です。

- [ ] リポジトリが **Private** になっている（Settings → General の一番下「Danger Zone」で確認できます）
- [ ] マイナンバー・パスワード・口座番号やカード番号の全桁を書いたノートがない（番号は末尾4桁まで）
- [ ] `.env` や鍵ファイル（`*.key` / `*.pem` / `*.p12`）を Vault に置いていない（`.gitignore` で除外済みですが、念のため）
- [ ] 家族・医療などの暮らしの情報を GitHub に置きたくない場合は、`.gitignore` の末尾にある「【任意】20_PERSONAL の中身を Git に入れない」の行を有効にした
  - これで Git から外れるのは、`20_PERSONAL/` にあなたが書いたノート（フォルダの説明ノートと `AGENTS.md`・`CLAUDE.md` は残ります）と、AI が `20_PERSONAL` から集計したレポート（`00_AI/reports/personal/`）です。`20_PERSONAL/` の PDF・画像（Obsidian がノートの隣の `attachments/` フォルダに保存する添付ファイルを含む）は、`.gitignore` のいちばん下の PDF・画像の行の「# 」も外したときだけ外れます
- [ ] 誰かを招待（Collaborators）していない、または招待した相手に見せてよい内容だけになっている

## 0. Obsidian のインストール

Obsidian は、メモ（Markdown ファイル）を読み書きする無料アプリです（個人利用は無料）。すでに入れている人は「5分導入手順」へ進んでください。

1. 公式サイト <https://obsidian.md> を開き、「Download」から自分の環境用をダウンロードします
   - **Mac**: ダウンロードした `.dmg` を開き、Obsidian のアイコンを「アプリケーション」フォルダへドラッグします
   - **Windows**: ダウンロードした `.exe` を実行し、画面の案内に従います
   - **iPhone / Android**: App Store / Google Play で「Obsidian」を検索してインストールします（まずはパソコン版で試すのがおすすめです）
2. このパッケージを手元に用意します（「入手方法」の A: ZIP を展開したフォルダ、または B: **Private** で作った自分用リポジトリをクローンして手元にコピーしたフォルダ）
3. Obsidian を初めて起動したら **「フォルダを保管庫として開く」** を選び、手順 2 のフォルダを指定します（保管庫 = Vault は「メモを入れるフォルダ」のことです）
4. 次のようなダイアログが出ることがあります。
   - **「作者を信頼してプラグインを有効化」/ 制限モードの確認**: Obsidian は安全のため、初期状態では「他人が作った追加機能（コミュニティプラグイン）」を動かさない設定（制限モード）です。最初の1ノートはコミュニティプラグインなしで作れるので、**まずは「信頼せず開く」でも問題ありません**。プラグインを使いたくなったら、「見た目とプラグインのセットアップ（任意・あとでOK）」の手順 1 でオフにします

## 5分導入手順

1. **入手する**: ZIP をダウンロードして好きな場所に展開します（おすすめ）。「Use this template」を使う場合は **必ず Private** を選び、作ったリポジトリをクローンして手元にコピーします（→「入手方法」）
2. **Obsidian で開く**: Obsidian の「フォルダを保管庫として開く」で、展開（またはクローン）したフォルダを選びます。貼り付けた画像やPDFは、そのノートと同じフォルダの `attachments/` に保存されます。まず `Home.md` を開いてください
3. **最初の1ノートを作る**: 次の「最初の1ノートを作ってみよう（サブスク1件）」に進みます（テンプレートとデイリーノートの設定は同梱済みで、追加のプラグインは不要です）。見た目とプラグインのセットアップは、そのあとの任意の手順です
4. **AI ツールをこのフォルダで起動する**: ターミナルを、このフォルダ（Vault）を開いた状態で立ち上げてから AI を起動します。展開・クローンした場所は人それぞれなので、パスを打ち込まずに次の方法で開きます
   - **Mac**: ターミナルを開き、`cd `（最後に半角スペースを入れる）と打ちます。そのまま Finder から Vault のフォルダをターミナルの画面へドラッグ＆ドロップして、Enter を押します
   - **Windows**: エクスプローラーで Vault のフォルダを開き、上のアドレスバーに `cmd`（または `powershell`）と入力して Enter を押します。そのフォルダでターミナルが開きます
   - そのあと AI ツールを起動します。Claude Code なら `claude`、Codex なら `codex` と入力して Enter です
   - Claude のデスクトップアプリの「Code」タブなら、画面でフォルダを選ぶだけで始められます
   - Cursor などのエディタ型ツールなら、このフォルダを「フォルダを開く」で開きます
5. **AI に最初のひと言**: 「AGENTS.md を読んで、このVaultのルールを3行で説明して」と頼んでみてください。ルールを理解していれば準備完了です

> `50_PEOPLE` / `60_ORGANIZATIONS` / `70_TOPICS` にある「サンプル」と書かれたノートについて: サンプルノートは削除してOK（このパッケージ同梱の例のため）。それ以外のノートは削除せず `90_ARCHIVE/` へ移動するのがこの Vault のルールです。

## 最初の1ノートを作ってみよう（サブスク1件）

最初の目標は **1ノートだけ** です。契約しているサブスク（動画配信・音楽・クラウドなど）を1件選んで、次の手順で書いてみましょう。
テンプレート機能（コアプラグイン「テンプレート」）のテンプレートフォルダは、このパッケージで **`99_TEMPLATES` に設定済み** なので、追加の設定はいりません。

1. **フォルダを開く**: 左のファイルエクスプローラーで `20_PERSONAL` → `アカウント・契約` を開きます
2. **新しいノートを作る**: `アカウント・契約` フォルダを **右クリック →「新規ノート」** を選びます（フォルダの中に「無題のファイル」ができます）
3. **名前を付ける**: ノートの名前をサービス名にします。例: `サンプル動画配信`（Obsidian が `サンプル動画配信.md` として保存します）
4. **テンプレートを入れる**: ノートの本文をクリックしてから **Cmd+P（Windows は Ctrl+P）** でコマンドパレットを開き、「**テンプレート: テンプレートを挿入**」→ `subscription` を選びます
   - ノートが編集できない（文字を打てない）ときは、右上の **本／鉛筆のアイコン** を押すか、**Cmd+E（Windows は Ctrl+E）** で編集表示に切り替えます
5. **最低限だけ埋める**: 上のプロパティ欄の `service`（サービス名）・`monthly_fee`（月額）・`renewal_date`（更新日）の3つだけ入れれば完成です。表や解約方法は、あとから少しずつで大丈夫です

> パスワードは書かないでください（パスワード管理アプリに置きます）。支払いカードを書くなら末尾4桁までにします。

慣れてきたら同じ手順で2件目・3件目を足し、AI に「サブスクの月額合計と、来月更新のものを一覧にして」と頼んでみてください。

## 見た目とプラグインのセットアップ（任意・あとでOK）

最初の1ノートを書けたら、余裕のあるときに進めてください（5分ほど）。このパッケージには、アイコン・色・テーマ・プラグインの**設定だけ**が入っています（プラグイン本体は入っていません）。次の手順で本体を入れると、設定が自動で反映されます。画面の言葉は日本語表示の場合のものです。

1. **制限モードをオフにする**: 左下の歯車（設定）→「コミュニティプラグイン」→「コミュニティプラグインを有効化」（制限モードをオフにする）をクリック
2. **プラグインを入れる**: 同じ画面の「閲覧」をクリック → 検索欄に下表の検索語を入力 → 該当プラグインを選んで「インストール」→「有効化」。これを 5 つのプラグインそれぞれで繰り返します
3. **テーマを入れる**: 設定 → 「外観」→「テーマ」の「管理」（または「テーマを管理」）→ 検索欄に `Minimal` と入力 → 「インストールして使用」
4. **Git は任意**: GitHub でバックアップしたい人だけ使います。**最初は不要です**。入れる場合も、同梱設定は自動コミット・自動 push・自動 pull をすべてオフにしてあります
5. **CSS スニペットを確認**: 設定 → 「外観」→「CSS スニペット」に 4 つ（headings-clean / sidebar-spacing / table-mac-style / sidebar-unified）が並び、オンになっていれば OK。表示されないときは右の更新ボタンを押します

### 同梱プラグイン一覧

| プラグイン | 検索語（閲覧） | あなたにとっての役割 | 必須 / 任意 |
|---|---|---|---|
| Iconic | `Iconic` | フォルダやファイルに色付きアイコンを付ける。フォルダが見分けやすくなる | 必須（見た目の中核） |
| Minimal Theme Settings | `Minimal Theme Settings` | Minimal テーマの幅・配色などを調整する | 必須（Minimal テーマを使う場合） |
| Dataview | `Dataview` | ノートを検索・一覧表にする（AI が作る一覧ノートで使う） | 推奨 |
| Calendar | `Calendar` | 右サイドバーにカレンダーを出し、クリックでデイリーノートを開く | 任意 |
| Recent Files | `Recent Files` | 最近開いたノートの一覧を出す | 任意 |
| Obsidian Git | `Git` | GitHub へのバックアップ | 任意（最初は不要） |

> Dataview の「DataviewJS」（JavaScript を使う機能）は、コードを実行できるため **初期状態でオフ** にしてあります。必要なときだけ、クエリの出どころを信頼できる場合にオンにしてください。

### うまくいかないとき

- **アイコンが出ない** → Iconic が「有効化」されているか確認（設定 → コミュニティプラグイン → インストール済み）
- **テーマが反映されない** → 設定 → 外観 →「テーマ」で Minimal が選ばれているか確認
- **日本語表示にしたい** → 設定 → 一般 →「言語」で「日本語」を選ぶ

## 中核は 20_PERSONAL

このキットのいちばん大事な部分は `20_PERSONAL/` です。保険証券、医療費の領収書、サブスクの契約、口座の一覧……暮らしの情報は書類やアプリにばらばらに散らばりがちです。分野別のフォルダに集めておくと、AI に「今年の医療費は？」「保障が重複していない？」「来月更新のサブスクは？」と聞くだけで答えが出るようになり、家族にとっての「もしもの時」の案内にもなります。

| フォルダ | 置くもの |
|---|---|
| `家族/` | 家族1人1ノート（`家族_名前.md`）・緊急連絡先・記念日 |
| `医療・健康/` | 通院・処方・検診・医療費（医療費控除の準備に使う） |
| `保険/` | 保険（契約ごとに1ノート。自動車・火災保険もここ）・保障の重複チェック |
| `財務/` | 家計・口座・資産スナップショット・ローン・クレカ |
| `税務/` | 確定申告・源泉徴収票・ふるさと納税・住民税 |
| `住まい/` | 契約・修繕・家電の保証書 |
| `車・乗り物/` | 車検・整備記録（保険の契約ノートは `保険/` へリンク） |
| `教育・子育て/` | 学校・習い事・費用（子どものプロフィールは `家族/` のノートへリンク） |
| `仕事・キャリア/` | 職務経歴・自己分析・資格 |
| `旅行/` | 1旅行1ノート |
| `趣味/` | 趣味ごとにサブフォルダ |
| `アカウント・契約/` | サブスク・各種サービス（パスワードは書かない） |
| `もしもの時/` | どこに何があるかのリンク集（家族向け） |

### まずは 20_PERSONAL の「保険」か「サブスクの棚卸し」から始めよう

- **保険**: 手元の保険証券を見ながら、`99_TEMPLATES/insurance` で契約ごとに1ノート作ります。数件そろったら AI に「保険の保障内容が重複していないかチェックして」と頼んでみてください
- **サブスクの棚卸し**: クレジットカードの明細を見ながら、`99_TEMPLATES/subscription` で1サービス1ノート作ります。AI に「サブスクの月額合計と、来月更新のものを一覧にして」と頼むと、見直しのきっかけになります

> マイナンバー・パスワード・口座番号や証券番号の全桁は書かないでください（番号は末尾4桁まで）。

> [!IMPORTANT]
> **AIに個人情報を読ませる前に**
> - Claude・Codex などのクラウドの AI にノートを読ませると、そのノートの内容は **AI の提供元（その会社のサーバー）に送られて処理されます**
> - 医療・家族などのノートを AI に読ませるかどうかは、**あなた自身が決めること** です。読ませる前に、使っている AI サービスの利用規約と「学習に使わせない（オプトアウト）」設定を確認してください
> - このパッケージの AI 向けルールでは、AI はあなたが頼めば読みますが、その中身を関係のない別のノート・AI のメモリ・Web検索や翻訳などの外部サービスへ写さないことになっています。集計を頼んだときだけ、頼んだ合計と内訳・元ノートへのリンクを `00_AI/reports/personal/` に保存します

## AI への最初の頼み方（プロンプト例）

そのままコピーして使えます。

1. **ルール確認**
   > AGENTS.md を読んで、このVaultで守るべきルールを箇条書きで説明して。
2. **INBOX の整理**
   > 10_INBOX の中身を確認して、どこに振り分けるかを表で提案して。OK したら実行して。
3. **人物ノートの作成**
   > 今日の打ち合わせメモ（10_INBOX/打ち合わせメモ.md）に出てくる人を 50_PEOPLE にノート化して。既存ノートがあれば追記して。
4. **週次の振り返り**
   > 02_DAILY の今週分を読んで、やったこと・決めたこと・持ち越しを 00_AI/reports/ にまとめて。
5. **医療費の集計（20_PERSONAL）**
   > 20_PERSONAL/医療・健康 の今年のノートから支払額を集計して、補填額を差し引き、要確認の項目を列挙して。元ノートへのリンクと計算日を付けて 00_AI/reports/personal/ に保存して。

   医療費控除の金額そのものは、国税庁のルールで確認するか、税理士に確認してください（AI の集計は下準備です）。医療のノートを AI に読ませる前に、上の「AIに個人情報を読ませる前に」も確認してください。
6. **つながりの発見**
   > 70_TOPICS/生成AI活用.md に関係しそうなノートを Vault 全体から探して、リンク候補を提案して。

コツ: 「どこに」「何を」「どう確認してから」を言うと、AI は迷いません。迷ったら AI は質問してくるので、答えてあげてください。

## 発展編

慣れてきたら、Vault を GitHub で管理して変更履歴を残したり（その場合も **Private** リポジトリにし、「GitHubに上げる前のチェック」を確認してください）、複数の AI に役割を分けたり（例: ひとつの AI が書き、別の AI が内容をチェックする）できます。共通ルールを `AGENTS.md` に一本化してあるのは、どの AI を使っても同じ前提で動けるようにするためです。まずは1つの AI で「書く→整理する→つなぐ」が回る状態を作ることを優先してください。
