# second-brain-starter — Obsidian × AI で始める「第2の脳」

Obsidian のフォルダ（Vault）に、AI が迷わず働けるルールとフォルダ構成をあらかじめ用意したスターターキットです。
ダウンロードして Obsidian で開き、同じフォルダで AI ツール（Claude Code / Codex / Cursor など）を起動すれば、すぐに「メモを書く → AI が整理する → 知識がつながっていく」運用を始められます。

- 対象: Obsidian を少し触ったことがあるビジネスパーソン（AI は初心者でOK）
- 必要なもの: [Obsidian](https://obsidian.md/)（無料）と、フォルダを読み書きできる AI ツールのどれか1つ

---

## これは何か

「第2の脳」とは、頭の中に置いておくと忘れてしまう情報（人・会社・仕事・考えたこと）を外に書き出し、あとから取り出せるようにする仕組みです。
このキットは次の3つを用意しています。

1. **フォルダ構成** — 人・組織・テーマ・仕事の4つの軸で情報を整理する
2. **AI 向けルール**（`AGENTS.md`） — どの AI でも同じルールで動くようにする
3. **テンプレートとサンプル** — 何をどう書けばいいかが一目でわかる

---

## 5分導入手順

1. **入手する**: GitHub の「Use this template」で自分用のリポジトリを作るか、ZIP をダウンロードして好きな場所に展開します
2. **Obsidian で開く**: Obsidian の「保管庫としてフォルダを開く」で、展開したフォルダを選びます。まず `Home.md` を開いてください
3. **テンプレート機能を有効にする**: 設定 → コアプラグイン →「テンプレート」をオン → テンプレートフォルダに `99_TEMPLATES` を指定します（デイリーノートも使うなら「デイリーノート」をオンにし、保存先を `02_DAILY`、テンプレートを `99_TEMPLATES/daily` にします）
4. **AI ツールをこのフォルダで起動する**: ターミナルでこのフォルダに移動してから AI を起動します
   ```bash
   cd ~/second-brain-starter   # 展開した場所
   claude                      # Claude Code の場合（Codex なら codex など）
   ```
   Cursor などのエディタ型ツールなら、このフォルダを「フォルダを開く」で開きます
5. **AI に最初のひと言**: 「AGENTS.md を読んで、このVaultのルールを3行で説明して」と頼んでみてください。ルールを理解していれば準備完了です

> サンプルノート（`50_PEOPLE` / `60_ORGANIZATIONS` / `70_TOPICS` にある「サンプル」と書かれたもの）は、仕組みを理解したら削除して構いません。

## フォルダの役割

| フォルダ | 役割 | 例 |
|---|---|---|
| `00_AI/` | AI の作業場 | AI が書いたレポート・ログ・引き継ぎメモ |
| `01_MANUALS/` | ルールと使い方 | 命名規約、AI との付き合い方 |
| `02_DAILY/` | デイリーノート | `2026-10-27.md` |
| `10_INBOX/` | とりあえず放り込む場所 | 思いつきメモ、会議の走り書き |
| `20_PERSONAL/` | **中核**: 暮らしの情報 | 家族・医療・保険・財務・税務・住まい・サブスク・もしもの時 など13分野 |
| `30_WORK/` | 仕事のこと | `projects/` に1プロジェクト1フォルダ |
| `50_PEOPLE/` | 人（1人1ノート） | `サンプル株式会社_山田太郎.md` |
| `60_ORGANIZATIONS/` | 組織（1組織1ノート） | `サンプル株式会社.md` |
| `70_TOPICS/` | テーマ（1テーマ1ノート） | `生成AI活用.md` |
| `80_LIBRARY/` | 外部資料・Webクリップ | 記事の要約、書籍メモ |
| `90_ARCHIVE/` | 使わなくなったもの | 削除の代わりにここへ |
| `99_TEMPLATES/` | テンプレート | 人・組織・テーマ・プロジェクト・デイリー・保険・受診記録・サブスク・旅行 |

## 中核は 20_PERSONAL

このキットのいちばん大事な部分は `20_PERSONAL/` です。保険証券、医療費の領収書、サブスクの契約、口座の一覧……暮らしの情報は書類やアプリにばらばらに散らばりがちです。分野別のフォルダに集めておくと、AI に「今年の医療費は？」「保障が重複していない？」「来月更新のサブスクは？」と聞くだけで答えが出るようになり、家族にとっての「もしもの時」の案内にもなります。

| フォルダ | 置くもの |
|---|---|
| `家族/` | 家族プロフィール・緊急連絡先・記念日 |
| `医療・健康/` | 通院・処方・検診・医療費（医療費控除に使う） |
| `保険/` | 保険（契約ごとに1ノート）・保障の重複チェック |
| `財務/` | 家計・口座・資産スナップショット・ローン・クレカ |
| `税務/` | 確定申告・源泉徴収票・ふるさと納税・住民税 |
| `住まい/` | 契約・修繕・家電の保証書 |
| `車・乗り物/` | 車検・保険・整備記録 |
| `教育・子育て/` | 子ども1人1ノート＋学校・習い事・費用 |
| `仕事・キャリア/` | 職務経歴・自己分析・資格 |
| `旅行/` | 1旅行1ノート |
| `趣味/` | 趣味ごとにサブフォルダ |
| `アカウント・契約/` | サブスク・各種サービス（パスワードは書かない） |
| `もしもの時/` | どこに何があるかのリンク集（家族向け） |

### まずは 20_PERSONAL の「保険」か「サブスクの棚卸し」から始めよう

- **保険**: 手元の保険証券を見ながら、`99_TEMPLATES/insurance` で契約ごとに1ノート作ります。数件そろったら AI に「保険の保障内容が重複していないかチェックして」と頼んでみてください
- **サブスクの棚卸し**: クレジットカードの明細を見ながら、`99_TEMPLATES/subscription` で1サービス1ノート作ります。AI に「サブスクの月額合計と、来月更新のものを一覧にして」と頼むと、見直しのきっかけになります

> マイナンバー・パスワード・口座番号や証券番号の全桁は書かないでください（番号は末尾4桁まで）。

## 最初の1週間でやること

| 日 | やること |
|---|---|
| 1日目 | `Home.md` と `01_MANUALS/AIとの付き合い方.md` を読む。`20_PERSONAL/保険/` か `20_PERSONAL/アカウント・契約/` に3件書いてみる |
| 2日目 | よく会う人を3人、`50_PEOPLE/` にノート化する（AI に頼んでもOK） |
| 3日目 | 自分の会社・主な取引先を `60_ORGANIZATIONS/` に作り、人のノートからリンクする |
| 4日目 | 思いついたことを `10_INBOX/` にどんどん放り込む |
| 5日目 | AI に「INBOX を整理して」と頼み、振り分け案を確認して実行してもらう |
| 6日目 | 今進めている仕事を1つ、`30_WORK/projects/` にフォルダ化する |
| 7日目 | AI に「今週のデイリーノートを振り返って要点をまとめて」と頼む |

## AI への最初の頼み方（プロンプト例）

そのままコピーして使えます。

1. **ルール確認**
   > AGENTS.md を読んで、このVaultで守るべきルールを箇条書きで説明して。
2. **INBOX の整理**
   > 10_INBOX の中身を確認して、どこに振り分けるかを表で提案して。OK したら実行して。
3. **人物ノートの作成**
   > 今日の打ち合わせメモ（10_INBOX/打ち合わせメモ.md）に出てくる人を 50_PEOPLE にノート化して。既存ノートがあれば追記して。
4. **週次の振り返り**
   > 02_DAILY の今週分を読んで、やったこと・決めたこと・持ち越しを 00_AI/reports/ にまとめて。
5. **医療費の集計（20_PERSONAL）**
   > 20_PERSONAL/医療・健康 から今年の医療費を集計して、医療費控除の対象額を出して。元ノートへのリンクと計算日を付けて 00_AI/reports/ に保存して。
6. **つながりの発見**
   > 70_TOPICS/生成AI活用.md に関係しそうなノートを Vault 全体から探して、リンク候補を提案して。

コツ: 「どこに」「何を」「どう確認してから」を言うと、AI は迷いません。迷ったら AI は質問してくるので、答えてあげてください。

---

## 発展編

慣れてきたら、Vault を GitHub で管理して変更履歴を残したり、複数の AI に役割を分けたり（例: ひとつの AI が書き、別の AI が内容をチェックする）できます。共通ルールを `AGENTS.md` に一本化してあるのは、どの AI を使っても同じ前提で動けるようにするためです。まずは1つの AI で「書く→整理する→つなぐ」が回る状態を作ることを優先してください。
